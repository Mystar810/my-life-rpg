显示数据库初始化 SQL

在 Supabase Dashboard → SQL Editor 中运行以下语句，开启用户隔离的云端存储。

create table if not exists public.rpg_saves (user_id uuid primary key references auth.users(id) on delete cascade, data jsonb not null default '{}'::jsonb, updated_at timestamptz not null default now());
alter table public.rpg_saves enable row level security;
create policy "users manage own save" on public.rpg_saves for all using (auth.uid() = user_id) with check (auth.uid() = user_id);

🛠️ 使用说明与限制

  • 目前是单用户原型，任务完成后 XP/GP 自动结算，重复点击不会重复奖励。
  • 任务日期用于日历与甘特图；预计时长决定计划条长度，实际时长由计时器记录。
  • 本地数据与云端数据是两种保存方式。首次云同步前建议先导出备份。
  • GitHub Pages 可以托管静态网页；如要云同步，需配置 Supabase URL/key、数据库表和登录重定向域名。
