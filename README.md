# My Life RPG · 人生冒险日志 v0.3

基于你提供的 v0.2 继续更新。静态网页，无构建步骤。保留原来的深色紫蓝仪表盘、任务、角色、计时、商店和 Supabase 配置入口。

## 本次完成

- 旅程规划：默认未来7天，可展开30天；按周查看预计剩余投入和可用余量。可以编辑任务、减少范围、改日期、暂停和恢复。未排期／暂停事项独立收纳。
- 今日参考线：位于日程页，可折叠；展示已投入、参考投入和可投入时间；按所选日期手动设置或关闭，可设休息日。实际投入增加不会提高参考目标。
- 三类目标：终点型、成长型、持续经营型；支持阶段里程碑。成长型与持续经营型不显示永久完成百分比、不设置强制截止。
- 已完成目标排在后面并加金色边框；新任务不再提供已完成目标。编辑原来关联已完成目标的任务时，保留原关联，避免丢失历史。
- 重要程度四级：低／一般／重要／关键。紧急程度四级：慢慢做／不急／紧急／非常紧急。列表使用星号和闪电级数，悬停／辅助阅读可读取完整说明，修复表单与列表文字不一致。
- 日期范围任务：填写计划日期和“持续至”日期，范围内未完成任务持续出现在日／周／月日程和甘特图。甘特图不再把预计分钟数粗略换算成天数。
- 截止提醒：独立恶龙主题列表，首页最多展示两条近期事项；逾期仍给正常基础奖励。暂停的事项仍保留截止提醒。
- 限次奖励：设置剩余次数，兑换后扣减，用完移出可兑换列表；兑换历史保留。增加图标候选。
- 金币换算：设置1元对应多少GP；新奖励可输入现实金额自动换算，四舍五入且至少1GP；修改比例不改已有价格。
- 复盘：周／月／年／自定义及历史周期切换、概况卡片、投入趋势、环形图按类型→具体目标→任务深入、星期平均节奏、可点开的每日热力图、目标和里程碑足迹。任务明细和属性成长默认折叠。
- 统计统一采用计时发生日期，正在进行的任务已记录计时也进入当期；无实际计时的已完成任务才在完成日使用修正时长或预估。避免任务跨周期完成后把过去的计时整体搬到本期。
- 日均投入明确按周期内截至今天的自然日计算；另显示有投入记录日均。未来日期、未记录日期单独标识。
- 存档兼容迁移；修改时更新本地保存时间。升级、导入或云端覆盖前保留一份本地恢复快照；设置中可恢复。恢复快照仅保留最近一份，不能替代JSON备份。
- 修复重复任务撤销完成再完成时重复生成后续任务的问题；逾期重复任务完成后从当前日期向后生成，避免连续补出过去的任务。
- 修正等级条的分母显示，使其与当前每100XP升级的既有规则一致；本次没有变更经验曲线或重算历史奖励。

## 升级到 GitHub Pages

1. 在当前线上版本的“设置”中导出最新 JSON 存档，保留好原 ZIP。
2. 解压更新包。将 `index.html`、`sw.js`、`manifest.webmanifest`、`README.md`、`supabase.sql` 覆盖到原仓库根目录。测试文件与说明文件不影响运行，可不上传。
3. 提交并等待 GitHub Pages 发布，继续使用原来的网址。无需新建网站、重新建表或清空数据。
4. 若显示旧版，关闭旧标签和已安装窗口再打开；必要时在 Edge 的站点应用管理里更新缓存。不要选择清除站点数据，否则会清除本地存档。
5. 核对角色经验、金币、任务和最近记录；必要时导入步骤1的JSON。
6. 先在一台设备确认新版本和存档，再在另一台设备打开，检查云端同步。该版本没有在你的真实 Supabase 账户上做联网验证。

同一个网址和浏览器下沿用 `myLifeRpgV1`。本地文件、不同域名、不同浏览器是不同存储空间，需用JSON或已有云同步迁移。

## 统计与规划边界

- 日历时间轴仍按开始时间所在小时排列，标明完整分钟时段；不是按分钟比例定位或支持拖拽的专业日历。
- 规划采用“总预计分钟减已记录计时”，在计划日期至持续日期／截止日期间平均分配。仍需手动调整任务量，尚未实现自动预测或重新排日历。
- 每日可投入时间目前是统一参考值，未实现每个星期几或每个日期的独立容量。
- 自动参考线采用任务预计时间按日期范围分配；与规划页扣除计时后的剩余工作量含义不同。完成当天仍保留参考份额。也可以指定当天参考分钟，或不设参考线。
- 暂停不改截止日期。对于明确截止事项，仍建议查看提醒并决定是否调整。
- 环形图包括自由计时；删除任务后保留的计时归入自由／历史计时。
- 选择自定义周期最多367天；年视图趋势按月汇总，热力图可滚动。
- 没有独立的“确认零投入”操作，当前无记录统一标为未记录。
- 云同步仍是原来的整份存档同步，未增加跨设备字段级合并、冲突历史或实时协作。

## 开发验证

`tests/regression.cjs` 使用 jsdom 运行12组回归场景，覆盖存档迁移、统计口径、表单校验、三类目标、限次奖励、换算、日期范围、暂停、参考线、图表下钻、重复任务及逾期正常奖励。

开发者可自行安装 jsdom 后执行：`node tests/regression.cjs`。最终用户无需安装 Node 或任何依赖。

浏览器离线功能需要通过HTTP/HTTPS访问。Supabase客户端仍来自CDN，离线或网络受限时本地功能可用，但云同步可能无法加载。
